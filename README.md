# JEEVA-SAVA
# 🚑 Jeeva Sava – Domestic Ambulance Service System

## 📌 Project Overview

**Jeeva Sava** is a web-based application designed to provide **quick and reliable domestic ambulance services**. The system helps users easily book ambulances in emergency situations and enables service providers to manage requests efficiently.

---

## 🎯 Objectives

* To provide fast ambulance booking during emergencies
* To reduce response time using digital platforms
* To connect users with nearby ambulance services
* To improve healthcare accessibility

---

## 🚀 Features

### 👤 User Features

* User Registration & Login
* Book Ambulance Online
* View Available Ambulances
* Emergency Contact Option
* Track Booking Status

### 🛠️ Admin Features

* Manage Ambulance Details
* Assign Ambulances to Requests
* View Booking History
* Manage Users

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/jeeva-sava.git
```

2. Navigate to the project folder:

```
cd jeeva-sava
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the application:

```
python app.py
```

5. Open in browser:

```
http://127.0.0.1:5000/
```

---

## 📊 System Workflow

1. User registers/logs in
2. Requests ambulance service
3. System checks availability
4. Admin assigns ambulance
5. User receives confirmation
